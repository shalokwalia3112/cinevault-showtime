# CineVault Reborn

Build the CineVault movie streaming web app recreating the exact dark theme, layout, and visual styling from the attached screenshots. Use the TMDB API (API key: 72a973eacb92793f0dd2a67b5ee47e83) to fetch real movie data, posters, ratings, genres, and overviews. Include the top navigation (CINEVAULT brand with clapperboard icon, Home, Browse, Search), featured hero section (trending title, star rating, release year, genre tags, description, lime-yellow Play button, More Info button), and horizontal scrolling poster carousels ("Trending Now", "Popular on CineVault") with rating badges. Configure the movie Play button to open a widescreen video modal embedding the player iframe from https://vidsrc.sbs.
